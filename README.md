# Лабораторная работа 1 — скрипт для сборки

## Использование
```sh
chmod +x build.sh
./build.sh examples/hello.c      # -> examples/hello
./build.sh examples/hello.cpp    # -> examples/hello_cpp
./build.sh examples/report.tex   # -> examples/report.pdf
echo $?                          # код завершения
sh test.sh                       # автоматическая проверка всех случаев
```

Имя конечного файла задаётся комментарием в исходнике:

Язык   Комментарий
C/C++  `// Output: hello` или `/* Output: hello */`
TeX    `% Output: report.pdf`

## Коды завершения
Код    Значение
0      успех
1      неверные аргументы
2      исходный файл не существует / не читается
3      неподдерживаемый тип файла
4      нет комментария `Output:` / некорректное имя
5      компилятор не найден
6      не удалось создать временный каталог (`mktemp`)
7      ошибка компиляции
8      не удалось записать результат рядом с исходником
128+N  прерван сигналом N (129 HUP, 130 INT, 131 QUIT, 141 PIPE, 143 TERM)

## Как это устроено
1. `trap cleanup EXIT` — при любом выходе удаляется временный каталог (`rm -rf`).
2. На `HUP INT QUIT PIPE TERM` стоит `on_signal`, он делает `exit 128+N`, срабатывает `cleanup`.
3. Компилятор запускается в фоне и дожидается через `wait`. Так сделано потому, что `wait`
   прерывается сигналом сразу, а при обычном запуске оболочка обработала бы ловушку только
   после завершения компилятора. `cleanup` также завершает ещё работающий компилятор.
4. `mktemp -d` создаёт каталог, скрипт делает в него `cd`, так что все промежуточные файлы
   (`*.o`, `*.aux`, `*.log`) создаются там. Для TeX используется `-output-directory`.
5. Имя результата извлекается через `grep -E` + `sed`, запрещены `/`, `.` и `..`.
6. Результат копируется во временное имя рядом с исходником, потом переименовывается через `mv`.
